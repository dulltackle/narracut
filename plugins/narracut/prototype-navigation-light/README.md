# 项目入口与导航原型（已确认）

2026-09-12，用户试用多轮后表示“我没有修改意见了”。本目录归档《确定项目入口、创作简报与配置的导航方式》的可丢弃原型，不是生产实现。

## 运行

打开 `index.html`，或在仓库根运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory plugins/narracut/prototype-navigation-light
```

全部状态仅存内存，刷新重置；不连接后端、不操作真实项目。

## 已确认方案

- 单行顶部导航：项目身份、分段工作区切换、项目工具、独立关闭项目。项目工具包括创作说明、声音配置、程序历史、项目检查，以描边按钮明确可点击；关闭项目使用分隔和独立低饱和暖色样式。
- 创作说明（Video Brief）不需经常对照，按需打开居中弹窗；离开编辑框保存，关闭保留工作区、所选 Scene 与滚动位置。保存后显示待复核信息，不把既有 Preview 撤销。
- 整部视频使用同一套 TTS 配置。新项目直接进入空表格，先写旁白；首次生成 Speech 时再配置声音，保存后继续原句生成，取消不生成。更换声音先明确已有 Speech 的失效范围。
- Scene 采用紧凑行：旁白随文本展开，Speech 状态与图标操作左右相邻。生成用麦克风图标，重新生成用循环箭头，均有 title 和 Scene 专属无障碍名称。
- 项目检查可定位 Scene；历史回退创建候选后进入 Agent 工作区，不直接切换当前修订；已有候选时禁止再创建。
- 项目信息居中显示，标题栏采用叉号关闭图标；底部取消、返回和主要动作保留文字。
- 项目创建／打开留在启动页，不强制先填写 Brief 或配置 TTS。系统目录选择只模拟其边界。
- 身份失效进入阻断页并提供恢复快照导出；离开未导出的内存成果前明确提示后果。
- 恢复先选快照，然后显示其中记录的原目录建议。用户点击“使用此目录并检查”明确来源；检查通过后展示可恢复内容和建议另存位置，允许更改，最后“恢复并打开项目”。不再要求额外勾选或手动选择三项。
- 恢复仍要求精确匹配来源和不存在的新目标；快照只含未落盘编辑，素材与程序来自来源目录。提示路径不是身份依据，不自动扫描替代来源。

## 试用与证据

底部模拟工具可切换首次创建、已有项目、长项目、身份失效、快照恢复。

已在 1200×720、960×640 与用户实际 902×667 内容视口核对。902px 顶部无横向溢出，短句行高约 49px，Speech 状态与操作间距 6px。尺寸是原型取值，不是宿主固定尺寸。

已核对首次配置取消／继续生成、声音更换取消保留已有 Speech、Brief 保存与滚动保留、历史候选跳转、创建项目清除旧候选、恢复返回和确认、关闭图标与无障碍名称。浏览器无脚本错误，设计检测无发现；多轮独立审阅结论可试用。

`evidence/final-*.png` 是最终截图；其他截图是方案演变的历史证据。全部截图来源为本地合成 HTML 原型，日期 2026-09-12；文件名注明内容视口宽度。底部黑色栏只属于原型工具。

## 范围限制

项目、声音、文件路径、Speech、检查和恢复均为模拟，无真实音轨或文件写入。恢复失配等细分异常、Brief 冲突、跨工作区控制权由后续状态决策承接。候选审阅仅导航占位，审阅交付规则沿用已确认的候选审阅决策。

未修改生产代码、DESIGN.md、项目格式或恢复协议。页面截图不代表真实 Codex 外层、系统目录窗口或真实后端验收。
