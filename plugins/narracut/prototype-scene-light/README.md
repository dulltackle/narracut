# Scene 内容编辑：可丢弃布局原型

用于试用连续修改多句 Narration、快速检查 Asset 与 Speech 的工作台交互。用户已选择 **A 全宽表格**，要求布局更加紧凑、同屏显示更多 Scene，不增加“保存并跳到下一句”快捷键。B 详情侧栏与 C 行内展开仅保留为比较资产。

路线图：[Narracut 浅色工作台与交互改版决策地图](https://github.com/dulltackle/narracut/issues/101)。完整决策统一记录于[确定 Scene 内容编辑的浅色工作台布局与操作方式](https://github.com/dulltackle/narracut/issues/103)，本文件仅说明原型试用与验证范围。

## 启动与试用

在本 README 所在目录运行：

```bash
python3 -m http.server 43103 --bind 127.0.0.1
```

打开 [本地原型 · A 全宽表格](http://127.0.0.1:43103/?variant=A)。默认加载 6 个合成 Scene，底部可选择 30 个 Scene 或空项目。

- 连续修改至少三句 Narration，检查原位编辑与失焦模拟保存是否顺手。默认行高为 82px，Narration 显示两行，编辑时按内容展开；观察展开是否影响上下文与连续操作。
- 扫读 Asset 和 Speech 状态，试用绑定、解除引用、生成及重试，再继续编辑 Narration。
- 切换至 30 个 Scene，检查同屏信息量、滚动和长文本编辑；切换空项目，试用添加 Scene。
- 按需试用复制、上移、下移、删除及撤销。B/C 可由底部或 URL 参数切换，用于回顾比较，不代表获选方案。

## 验证范围与限制

- `1200 × 720` 是首要模拟浏览器内容视口，`960 × 640` 用于压缩检查。截图和这些尺寸均不代表真实 Codex 外层宿主验收，真实宿主仍待后续验证。
- UI 字号 14px、Narration 字号 15px、按钮高度 32–34px，以及白底、近黑正文、灰色辅助信息和蓝色焦点提示，均为原型建议基线，未经 Codex 宿主实测。
- 所有数据仅存于页面内存，无真实文件读写、后端保存、Speech 生成或音频播放。刷新会丢失修改并恢复初始数据；切换合成场景会重置数据；切换布局保留当前内存数据。
- “原型条件与当前状态”可查看方案、所选 Scene 与模拟数据。
- 这是可丢弃的比较与试用资产，不是生产实现；将归档到独立 Git 分支，并由决策工单保留引用。
