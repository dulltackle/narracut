## Agent skills

### Issue tracker

Issues live as GitHub issues in [`dulltackle/narracut`](https://github.com/dulltackle/narracut). See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical roles (`needs-triage` / `needs-info` / `ready-for-agent` / `ready-for-human` / `wontfix`) are used as-is. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.

查找现行规范、模块说明或验收记录时，读 `docs/README.md`；只有追溯旧架构或历史证据时才读 `docs/archive/README.md`。
