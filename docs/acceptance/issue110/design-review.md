# #110 设计文档一致性检查

本次属于既有 Operate 浅色连续 Scene 表格的交互扩展，没有新的视觉体系或已批准的系统变更。对照已完成实现检查后，保留根目录 `DESIGN.md` 和 `.impeccable/design.json`，不重新生成设计规范。

## 检查依据

- `PRODUCT.md`、`CONTEXT.md`、ADR-0009：表格工作区管理 Scene 内容与顺序，保持内容和 Render Program 表现的编辑边界。
- `DESIGN.md` 及 `.impeccable/design.json`：#109 已确立的浅色连续编辑台、基础色、正文层级、控件与焦点规则。
- `plugins/narracut/workbench.html` 的最终 CSS 层叠：连续表格基础及本次 Scene 编排增量。
- `plugins/narracut/workbench.js`：工具栏、上下文菜单、菜单定位、键盘关闭和操作反馈实现。
- 视觉审阅已交付 902×667、960×640、1200×720、430×667 四档证据，位于 `.impeccable/review/issue110-*.png`；本次文档检查另外抽查 430px 菜单截图。视觉审阅结论由主验收记录承接，不把静态截图作为真实宿主或持久化行为的证明。

## 一致性结论

1. 白色工作面、近黑正文、灰色说明、浅灰分隔与深色新增按钮沿用既有系统。菜单没有引入新的品牌色或材料效果。
2. Narration 保持 14px、1.65 行高的中文 UI 字体；菜单操作采用已有 13px／500 层级，说明采用 12px 辅助文字，不另建展示字体体系。
3. 四列连续表格和随内容增长的行高保持不变。工具栏保留新增、撤销、重做及简短帮助；Scene 操作在指针或键盘入口打开的非模态菜单中呈现，不添加逐 Scene 卡片或新的常驻操作区。
4. 菜单复用 6px 控件圆角、2px 蓝色可见焦点及 700px 窄屏断点；桌面菜单操作最小高度 36px，窄屏为 44px。禁用边界同时展示文字原因，选择与键盘焦点有独立表达。
5. 删除及撤销说明保持轻量、可换行的浅色反馈；页面历史范围在工具栏直接说明。局部交互细节归入 #110 验收，不提升为所有界面的通用约束。

## 未纳入系统规范的差异

新上下文菜单使用 `0 8px 24px #00000024` 柔影，现有设计文件与 sidecar 记录的旧菜单柔影是 `0 8px 24px #00000014`。本次仅记录这一局部参数差异；它继续表达浮层关系，不代表已批准修改全局投影规则，因此不更新系统 token，也不声称两者数值完全一致。

既有样式中旧模块的历史变量名和局部色值仍存在，`DESIGN.md` 已明确它们不自动成为新品牌规范。本次不顺带修复这些漂移，也不将任何旧材料效果或缺陷记录为未来表面的规则。
