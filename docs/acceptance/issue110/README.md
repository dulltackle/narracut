# #110 Scene 编排与可撤销操作验收

2026-09-12，延续 #109 浅色连续表格，实施工单已确认的 Scene 编排交互。证据对应本目录所在提交；截图由生产工作台资源和合成项目数据生成，不是设计原型。

## 已实现的行为

- 工具栏保留新增、撤销和重做。新增插在所选 Scene 后并聚焦 Narration；没有选择时追加。按钮提示下一步历史操作，历史只保留在当前页面。
- 行右键或 Shift+F10／菜单键打开上下文菜单；复制、上下移、指定位置及删除在同一入口。方向键和 Tab 可导航，位置输入支持上下键调值、Enter 提交；Escape 或 Tab 越过首尾返回原行。
- 复制生成新 Scene ID，保留 Narration 和 Asset 引用，Speech 待生成；重排不改变身份。复制及排序后选中并定位对应 Scene，不自动编辑副本。
- 删除后优先选择原位置的下一句，否则前一句；可见反馈说明选择变化。删空聚焦新增首句。撤销恢复身份、内容与顺序，Asset 文件不被删除。
- 选择底色与键盘焦点描边分别表达；首尾排序和容量上限有禁用状态与原因。失去写权时关闭菜单并返回行，沿用共享保存、断连与恢复反馈以及服务端写屏障。
