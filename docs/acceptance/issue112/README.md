## 行为边界

- 当前／候选显式切换，新候选就绪保留原画面。打开抽屉继续播放，隐藏工作区暂停；关闭后焦点返回入口，Tab 与 Shift+Tab 留在抽屉内。
- 建议仅复制或定位；目标删除时定位禁用并解释。返回审阅保留同一 Preview 帧且暂停；输入改变标记旧画面过期，不把旧实例帧套到新实例。
- 硬阻断和非阻断警告直接显示。接受仍经过生产服务的最新身份与门禁核对，不提供覆盖硬阻断的确认。
- 返回入口位于独立容器，连续编辑与保存刷新不重建表格；最终 Render 的候选检查入口先打开抽屉再定位。
