## 已实现行为

- 单个与多个 Asset 均先进入右侧临时管理面板。面板目标与所选 Scene 分开保存；打开、只读预览及关闭保持选择与 Player 观看位置，关闭返回同行入口。
- 绑定、解除及顺序操作针对面板目标 Scene。解除不删除登记或源文件；未绑定与已绑定文件缺失分别说明。长名称同行省略，在面板完整换行，操作可以滚动与键盘到达。
- Speech 的状态、时长、生成／重试／取消继续同行。具体原因通过摘要另一侧的问题图标打开浮层；异常原因不增加 Scene 行高。图标有 Scene 专属无障碍名称及悬停说明，支持 Enter、空格、点击、外部点击及 Escape。
- 原因浮层随生成阶段更新保留焦点；成功后无原因时收起，原焦点位于浮层内则返回同行操作。任务完成不会抢走正在编辑的 Narration 焦点。
- Narration 修改立即移除旧 Speech 并显示待生成及原因，空 Narration 禁止生成。生成前等待保存；失败不发起生成，原因可查，恢复保存后可以重试。
- Speech 轮询回执只有在当前写权、保存状态、内容及请求版本仍匹配时才应用；存在新编辑时保留本地内容，之后通过最新工作台读取核对。断连仅显示最后确认状态，恢复连接后继续核对。
- Asset 非必需；缺少匹配 Speech 使用明确标记的草稿估算，只能参与 Preview，不能用于最终 Render。未修改 DSL、Runtime、Speech 时间权威、候选及接受规则。
