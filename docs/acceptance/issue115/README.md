# #115 分组项目工具栏与 Brief 编辑／冲突处理

本记录对应 #115 已确认的导航与 Brief 交互。页面使用生产工作台资源，截图采用明确的协议夹具；真实文件测试使用临时 Project VNext 项目和插件服务。均不代表真实 Codex 外层或系统目录选择窗口的人工验收。

## 实现范围

- 902px 及以上按项目文件夹、分段工作区、四个工具、独立关闭排列；更窄时分行，不横滚隐藏入口。项目信息居中显示完整文件夹名、路径与 Project ID。
- Brief 按需打开居中编辑弹窗，离开编辑框或关闭时保存。组合输入结束前不保存；后台刷新、往返弹窗保留文字、光标及阅读位置。
- 未保存、保存中、保存失败与外部冲突在共享区持续显示；失败后可返回编辑或明确重试，异步回执不抢走关闭后的焦点。
- 冲突保留本地、磁盘与共同基准。合并保存成功后才解除冲突；磁盘再次变化保留合并草稿。导出本地内容只写项目外文件，不解除冲突。放弃前说明本地与合并草稿损失并确认。
- 只读、断连、身份失效及关闭过程中禁止新编辑提交。身份恢复沿用既有恢复协议。关闭失败恢复输入；关闭成功停止执行并释放项目，保留持久内容与候选。
