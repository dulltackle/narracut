# #109 浅色工作台与连续 Narration 编辑验收

日期：2026-09-12。基线：`006dc4f`，叠加本票实现。范围来自 [#109](https://github.com/dulltackle/narracut/issues/109) 和父工单已确认的第一批交接；单行分组导航、候选审阅新布局和真实 Codex 宿主整体验收属于后续批次。

## 可观察结果

- 外层连接／重试页及工作台采用浅色基础；连接失败给出原因和重试入口，不自动打开外部浏览器。
- Scene 全宽四列同行显示，检查按需打开；短句紧凑，长 Narration 原位按内容展开，不增加保存后跳句快捷键。
- Narration 离开输入框保存；IME 组合期间不提交。增量更新保留输入节点、光标和滚动容器；同项目通知不清空本地草稿。写入按稳定 Scene ID，保存快照与版本一起捕获，旧回执不清除后续修改。
- 顶栏下方共享位置显示待保存、保存中和持久失败原因。切换工作区不被保存阻断；可以重试保存或返回原 Scene 编辑。Preview 构建、检查、接受和输出不能使用未保存输入。
- 已显示页面断连时保留画面及本地内容，暂时只读并标明任务为最后确认状态；重连先核对身份、写权和在途结果，不自动补交或继续已停止任务。
- 另一对话控制时界面与服务端均拒绝写入。任务变化不自动切换工作区；按需定位使用实际 Scene 元素，兼容长文本增高。

## 执行与证据

页面测试使用公开 MCP 工作台资源、浏览器操作和工具协议；故障场景通过公开请求边界注入。`panel-reconnect.spec.ts` 的新增场景运行真实本地面板和项目文件，核对重连后保存到 `project.json` 的 Scene ID 与完整文本。候选执行使用现有测试工具和认证执行胶囊，不把页面模拟当成真实创作。

| 验证 | 结果 |
| --- | --- |
| 组合输入、同项目刷新、工作区往返 | 保留完整文字与输入焦点，组合期间无保存请求 |
| 旧保存回执、普通失败、共享重试／返回 | 后续编辑仍待保存；共享入口恢复原句，重试写入最新内容 |
| 实际断连与重连 | 原页面文字保留，只读，手动重试后核对持久文件 |
| 控制权 | `workbench-panel.test.ts` 11 项通过，覆盖服务端拒绝；页面双对话及重新获得写权通过 |
| 长文本后的 Agent 建议定位 | 由产品“定位 Scene”入口到达目标并保持在视口内 |
| 窄屏水平滚动 | Speech 操作可达，表头与内容横向位置一致 |
| 格式边界 | 保持 1,000 Scene 与现行 Narration 字节／Unicode 容量校验 |
