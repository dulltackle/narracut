# #116 首次 Speech 配置与已有声音变更确认

本票将首次生成与顶部声音配置合并为同一项目级表单。沿用浅色工作台、TokenDance 提供方与会话凭据边界，不新增逐 Scene 配置。

## 可观察行为

- 首次生成记录稳定 Scene ID 与当时 Narration；取消不保存、不生成，关闭回到实际入口。
- 保存成功后重新读取持久项目，核对项目、写权、目标与内容。原句变化时显示最新文字，只有“生成最新内容”明确确认后才续生成；删除、变空或失权不会改为生成其他 Scene。
- 已有输出配置变更在同一面板展示受影响 Speech 数量、可展开 Scene 清单和失效后果，默认聚焦“返回修改”。影响范围变化需要重读项目并重新确认。
- 凭据替换不改变音频 profile。成功提交后旧 Speech 同步失效，旧配置在途合成结果不能写入。
- 加载失败可重新读取；保存失败保留表单并重试；回执不明保留同一个操作身份，核对原结果，避免重复保存或重复合成。操作记录仅保留在当前宿主会话，不进入项目；会话结束后不承诺找回未知回执。
- 配置成功而生成失败时明确配置已保存，原句可直接重试。只读保留查看；面板内 Tab 循环，Escape 返回入口。

## 验证入口与边界

`tests/e2e/tts-configuration.spec.ts` 通过生产插件工具和真实临时项目检查 `tts.json`、`project.json` 与 Speech 文件，覆盖首次配置、取消、保存失败／重试、文本变化后明确续生成、删除、变空、失权、凭据替换、影响范围变化、旧配置迟到结果、保存和生成回执丢失、生成回执期间失权后恢复、超过 128 次操作、加载失败、四档视口与键盘操作。提供方响应使用明确的测试替身，音频为 ffmpeg 生成的正弦波 MP3；时长由真实 ffprobe 探测，不是语音合成服务产物。

`tests/e2e/plugin-workbench.spec.ts` 保留既有生成阶段、Speech 时间窗、外部冲突及凭据输入保全回归。`tests/narracut-plugin.test.ts` 与 `tests/project-speech-vnext.test.ts` 验证公开服务协议、凭据不落盘、Speech 时间与内容记录。
