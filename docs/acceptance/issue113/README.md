日期：2026-09-12。代码基线为 `6ddaa32` 后的本次工作树；截图由 Chromium 页面自动化生成，属于页面／协议证据，不代表真实 Codex 右侧宿主验收。

## 实现

- 整体接受沿用完整后果摘要、非阻断警告与最新输入门禁。确认读取完成后聚焦取消；取消返回入口。
- 接受回执不完整或查询暂时失败时，保留请求身份并每 2 秒核对；候选刷新不会覆盖核对提示。查询入口与修订历史在只读状态仍可用，接受、放弃、停止及历史创建候选互斥。
- 放弃沿用候选、候选恢复检查点与任务检查点删除确认，保留当前修订；结果不明时每 4 秒读取持久候选，也可手动核对。停止结果查询不重发停止；只有服务端明确报告停止收尾尚未完成时，提供“重试停止收尾”。
- 接受查询仅报告持久修订及待收尾事实，不隐式清理。明确清理入口保留写权约束，失败不撤销接受；页面明确说明最终 Render 尚需独立发起。
- 接受、候选及任务回执验证必要身份和合法状态后才解除待核对状态。断连或写权撤销不阻止只读结果查询。
